PRE-DECLARED GRID (written 2026-09-30 before any event computation). K = 58 cells.
Data: Binance USDT-M 1m klines 2026-03-01..2026-09-29, all symbols in k1m except BTCUSDT, ETHUSDT (alts universe).
Alt index: equal-weight mean of 1m log-returns of all available alts at each minute (cumulated).
Relative move at minute t (close of minute t, known at t_close): rel_N(t) = [ln c_t - ln c_{t-N}] - [I_t - I_{t-N}].
Event: DUMP if rel_N <= -X%, PUMP if rel_N >= +X% (log % * 100). Per coin per cell: after an event, the coin is blocked
until the trade exits (non-overlapping trades; cooldown = H or until TP exit). Warm-up: 24 h history required.
Trade: FADE (dump -> LONG, pump -> SHORT) at OPEN of minute t+1; exit at CLOSE of minute t+H (time exit) or TP.
Costs (round trip, % of notional): BASE = 0.146 fee + 0.10 slippage = 0.246; LOW = 0.10 + 0.05 = 0.15; HIGH = 0.146 + 0.20 = 0.346.
Primary metric: net_base = side * (exit/entry - 1)*100 - 0.246.  Market-neutral metric: side*(r_coin - r_index) - 0.246 - 0.10 (hedge leg cost).
TRAIN = 2026-03-01..2026-06-30, TEST = 2026-07-01..2026-09-29.

GRID A (40 cells): side {DUMP, PUMP} x X {1, 1.5, 2, 3, 5}% x N {1, 3, 5, 15} min; H = 60, no filters.
GRID B (18 cells): base event X=2%, N=5 min, for each side {DUMP, PUMP}:
  B1-B4: H in {15, 30, 60(same as A), 240}  (B3 = A cell; counted anyway)
  B5: TP = +1.0% (limit at entry*(1+-1%), touched by 1m high/low), time cap 60 min
  B6: volume filter HIGH: quote volume over the N move minutes / (N * mean per-minute qv of preceding 24 h) >= 3
  B7: volume filter LOW: same ratio < 3
  B8: OI filter DOWN: Binance OI (5-min metrics, last snapshot with create_time <= t_close - 5 min) change over prior 30 min <= -0.5%  (liquidation / closing)
  B9: OI filter UP: same change >= 0  (fresh positioning)
Selection rule: winner = cell with highest TRAIN mean net_base among cells with TRAIN n >= 200 and TRAIN coin-clustered CI90 lower > 0.
If no cell passes, the verdict is negative. TEST is evaluated for the winner (decision), all cells are reported for transparency.
Reports (not selection): per month, per regime (trailing 7-day alt index return up/down, known at decision; and calendar week
index up/down, ex post), market-neutral, by coin liquidity tercile, clustered CI90 by coin and by ISO week, sum without top 10%, tails (q1, q5, min).
Whale add-on (Sept 12-29 only): event in Grid-A winner (or DUMP X=1.5 N=3 if no winner, matching prior R1) flagged if a tracked whale close tx
(whale_txs, tx_usd >= 5000, in the same direction as the move: DUMP <- whale sells i.e. Close Long; PUMP <- Close Short) occurred in
[t - N min, t_close] on that coin; compare flagged vs unflagged.
